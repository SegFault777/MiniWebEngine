# Fonts

MiniWebEngine v0.4 draws text from vector outlines embedded in `mwe_font.h` (generated by
`tools/genfont.py`). Nothing is loaded at run time and no font library is used.

| Script | Font | Weights | Coverage |
|---|---|---|---|
| Latin, Greek, Cyrillic, symbols | **Inter** 4.000 | Regular, Bold (italics synthesized) | ASCII, Latin-1, Latin Extended-A, Greek, Cyrillic, common punctuation/arrows |
| Chinese (Simplified) | **Noto Sans CJK SC** 2.004 | Regular (bold synthesized) | GB2312: 6763 hanzi, symbols, kana, pinyin; CJK punctuation; full-width forms |

Copyright notices and the full OFL 1.1 texts: [`../NOTICE.md`](../NOTICE.md), `OFL-Inter.txt`,
`OFL-NotoSansCJK.txt`. Print them at run time with `mwe --licenses`.

> **About "Interop":** no font of that name exists. The request was read as **Inter**, which has
> no CJK glyphs, so Chinese uses Noto Sans CJK SC. To use a different Chinese font, regenerate the
> header (below).

## Regenerating `mwe_font.h`

```sh
pip install fonttools                        # build-time tool only
tools/regen_font.sh Inter-Regular.otf Inter-Bold.otf NotoSansCJK-Regular.ttc [1|2]
```

The last argument is the GB2312 level: `2` (default, 6763 hanzi, about 2.4 MB of outline data) or
`1` (3755 hanzi, about 1.3 MB). Use static fonts, not variable fonts. Characters a font lacks
render as `?`.

## Size options

- `-DMWE_NO_CJK` drops the Chinese font at compile time (CLI about 0.4 MB instead of about 2.7 MB).
- Hangul and Traditional-only characters are not embedded; `genfont.py` can be extended with
  another face the same way.
