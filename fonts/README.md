# Fonts

MiniWebEngine v0.5 draws text from vector outlines embedded in `mwe_font.h` (generated by
`tools/genfont.py`). Nothing is loaded at run time and no font library is used.

All text uses the **Noto Sans** family - **Noto Sans CJK SC** 2.004:

| Script | Weights | Coverage |
|---|---|---|
| Latin, Greek, Cyrillic, symbols | Regular, Bold (italics synthesized) | ASCII, Latin-1, parts of Latin Extended-A, Greek and Cyrillic, common punctuation/arrows (374 glyphs; what the font lacks renders as `?`, e.g. Greek tonos) |
| Chinese (Simplified) | Regular (bold synthesized) | GB2312: 6763 hanzi, symbols, kana, pinyin; CJK punctuation; full-width forms |

Copyright notice and the full OFL 1.1 text: [`../NOTICE.md`](../NOTICE.md), `OFL-NotoSansCJK.txt`.
Print the notice at run time with `mwe --licenses`.

> **About the Latin glyphs:** the Latin-only "Noto Sans" font was not available when v0.5 was built,
> so the Latin/Greek/Cyrillic outlines come from Noto Sans CJK SC (the same family; the Latin design
> differs slightly from the standalone Noto Sans). To use the standalone fonts, call
> `tools/genfont.py NotoSans-Regular.ttf NotoSans-Bold.ttf --cjk NotoSansCJK-Regular.ttc --cjk-index 2 ...`
> and update the notice strings and `OFL-*.txt` (Noto Sans: Copyright 2012 Google Inc., OFL 1.1).

## Regenerating `mwe_font.h`

```sh
pip install fonttools                        # build-time tool only
tools/regen_font.sh NotoSansCJK-Regular.ttc NotoSansCJK-Bold.ttc [1|2]
```

The last argument is the GB2312 level: `2` (default, 6763 hanzi, about 2.3 MB of outline data) or
`1` (3755 hanzi, about 1.3 MB). Use static fonts, not variable fonts.

## Size options

- `-DMWE_NO_CJK` drops the Chinese glyphs at compile time (CLI about 0.3 MB instead of about 2.7 MB).
- Hangul and Traditional-only characters are not embedded.
