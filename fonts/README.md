# Fonts

MiniWebEngine v0.2 renders text from **Inter** outlines that are embedded in the
binary as compact data (`mwe_font.h`, generated by `tools/genfont.py`). Nothing
is loaded at run time and no font library is used.

## Switching to Inter

```sh
pip install fonttools                       # build-time tool only
# download the static Inter TTFs from https://rsms.me/inter/ (SIL OFL 1.1)
python3 tools/genfont.py Inter-Regular.ttf Inter-Bold.ttf -o mwe_font.h
cp /path/to/Inter/OFL.txt fonts/OFL-Inter.txt   # keep Inter's own license text with the repo
```

Use the **static** Regular and Bold files, not the variable font. The generator
embeds ASCII plus a few typographic characters (NBSP, curly quotes, dashes,
bullet, ellipsis, arrow, euro, copyright, and similar). Inter has no Hangul/CJK glyphs.

## What the bundled `mwe_font.h` is

The `mwe_font.h` in this repository was generated from **Instrument Sans**
(SIL OFL 1.1, see `OFL-InstrumentSans.txt`) as a stand-in, because Inter was
not available when v0.2 was assembled. The header says so in its first line and
the CLI prints the font name in its usage text. Run the command above to replace it with Inter.
