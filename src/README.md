# MiniWebEngine source layout

`mwe.c` is a *unity build*: one translation unit that includes the modules below in dependency order.
That keeps every function `static` (no symbol clashes with the host, small and fast code) while the
source is split by responsibility. Build commands are unchanged: `cc -Os mwe.c -o mwe`.
`tests/clash.c` and CI check that no module introduces a name that collides with libc/POSIX/BSD.

| Module | Responsibility |
|---|---|
| `mwe_types.inc` | constants, `S` (string view), `Len`, `St` (computed style), `N` (DOM node) |
| `mwe_base.inc` | arena allocator, string helpers, strict UTF-8, glyph lookup and font metrics |
| `mwe_values.inc` | lengths, `calc()/min()/max()/clamp()`, units, colors |
| `mwe_decl.inc` | style defaults, custom properties / `var()`, the CSS declaration parser |
| `mwe_dom.inc` | DOM, HTML entities, HTML tokenizer and tree builder |
| `mwe_selectors.inc` | selector parser, `:is()/:where()` expansion, rules, `@media`/`@supports`, matching |
| `mwe_cascade.inc` | user-agent stylesheet, presentational attributes, generated content, the cascade |
| `mwe_raster.inc` | paint target, alpha blending, the vector-font rasterizer |
| `mwe_images.inc` | `<img>` store, `data:` URIs, image sampling |
| `mwe_boxes.inc` | box painter: borders, rounded corners, gradients, shadows, images in boxes |
| `mwe_layout.inc` | layout state, intrinsic sizes, block and inline layout, list markers |
| `mwe_flex.inc` `mwe_grid.inc` `mwe_table.inc` `mwe_abspos.inc` | flexbox, grid, tables, positioned boxes |
| `mwe_api.inc` | the public API of `mwe.h`, JavaScript glue, the command-line tool |
| `mwe_img.h` | standalone image decoders (PNG, JPEG, GIF, BMP); `tests/img/` tests them alone |
| `mwe_js.h` | the JavaScript engine (needs the engine's DOM types, so it is included late) |
| `mwe_font.h` | generated by `tools/genfont.py` (Noto Sans outlines) - do not edit |

Rules for new code: put it in the module that owns the concept; a module may use only what the modules
above it in `mwe.c` define; add a forward declaration in `mwe_types.inc` if an earlier module needs a
later function.
